# Lexiphon

The portfolio page of Nathaniel Robertson, content specialist, with Lexiphon, a brand voice written down as a profile and applied by rule.
It is a static site: no build step, no framework, no server code. GitHub Pages serves it from the root of `main`.

Live: https://nrr-hash.github.io/Lexiphon/

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | The page's markup and structured data. About 100 KB. |
| `css/site.css` | The page styles, including the font rules and the print styles. |
| `css/studio.css` | Styles for the Lexiphon studio. Loaded without blocking the first paint. |
| `css/fonts.css` | The font rules, used by `404.html`. The same rules are in `css/site.css`. |
| `js/page.js` | Widow control, the headline, Telltale, the page audit, and the sentence demonstrations. |
| `js/viewer.js` | The concept-page deep-zoom viewer. |
| `js/listen.js` | The Listen buttons on the demonstrations. |
| `js/lexicon.js` | The word lists: 236 rows of source words and what each archetype says instead, plus a patch table that fills thin voices. Every replacement is screened against the house slop lists. |
| `js/brand.js` | The voice profile: four tone dials (after the Nielsen Norman Group), five layers that follow them on Auto, the briefs, and the measures used to check a draft. |
| `js/engine.js` | Lexiphon's engine: sentence maths, the archetypes' word lists, and the rules that apply them. No page access. |
| `js/studio.js` | Lexiphon's interface: the profile, writing from a brief, checking a draft, the thesaurus, and the help. |
| `js/pwa.js` | Registers the service worker. |
| `js/vendor/three.min.js` | three.js r128 (MIT). Fetched only when the 3D section is about to be seen. |
| `fonts/` | Fraunces and Hanken Grotesk, Latin subsets, with their SIL Open Font Licence texts. |
| `images/` | Concept-page images and zoom tiles, archetype emblems, favicon, and social card. |
| `manifest.json`, `images/icons/` | The web app manifest and its icons, so the page can be installed to a home screen. |
| `sw.js` | The service worker, generated by `tools/build_sw.py`. Precaches the shell so repeat visits and offline visits work. |
| `llms.txt`, `llms-full.txt` | Plain-text summaries for answer engines, generated from the page by `tools/build_seo.py`. |
| `tools/build_sw.py` | Puts a content hash on every local stylesheet and script link, then regenerates `sw.js` from the page's own links. Run it after any change to the site: the hashes give changed files new addresses, and the cache name is a hash of the shell. |
| `tools/og.html` | The source of the social card (`images/og.png`). Open it in any headless browser at 1200 by 630 to render the image again after the headline changes. |
| `tools/make_icons.py` | Draws the app icons from code. |
| `tools/build_seo.py` | Regenerates the JSON-LD, the head tags, `llms.txt`, `llms-full.txt`, `sitemap.xml`, and `robots.txt`. `--check` writes nothing and reports whether they are stale. |
| `tools/check_seo.py` | Checks the structured data, FAQ parity, anchors, heading outline, and generated files. `--schema PATH` also checks property names against schema-dts' `schema.d.ts`. |
| `tools/make_previews.py` | Cuts the readable preview crops for the portfolio cards from the zoom tiles. |
| `tools/make_assets.py` | Regenerates the archetype emblems. |
| `tools/set_site_url.py` | Rewrites the public address everywhere it appears. Use it when moving to a custom domain. |
| `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll` | Hosting files for GitHub Pages. |

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000/. Serve over HTTP rather than opening the file, so the service worker and the scripts load as they do on the live site.

## Moving to a custom domain

1. Add a `CNAME` file containing the bare domain, and set the domain under Settings, Pages.
2. Run `python3 tools/set_site_url.py https://your.domain/` to update the canonical link, social tags, structured data, the link Telltale copies, `404.html`, `robots.txt`, `sitemap.xml`, `llms.txt`, and `llms-full.txt`.
3. Run `python3 tools/build_sw.py` so the service worker's cache name changes.

## Regenerating the emblems

    python3 tools/make_assets.py

## After editing the page

    python3 tools/build_seo.py
    python3 tools/build_sw.py
    python3 tools/check_seo.py

The concept-page images under `images/concepts/` and `images/work/` are not generated by this script.
