# Lexiphon

The portfolio page of Nathaniel Robertson, content specialist, with Lexiphon, a text-tuning studio built as a small synthesiser.
It is a static site: no build step, no framework, no server code. GitHub Pages serves it from the root of `main`.

Live: https://nrr-hash.github.io/Lexiphon/

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | The page: markup, page styles, and the page scripts. About 300 KB. |
| `css/studio.css` | Styles for the Lexiphon studio. Loaded without blocking the first paint. |
| `css/fonts.css` | The font rules, used by `404.html`. The same rules are inlined in `index.html`. |
| `js/synth.js` | The studio's audio engine. No DOM access, so it can be rendered offline and measured. |
| `js/vendor/three.min.js` | three.js r128 (MIT). Fetched only when the 3D section is about to be seen. |
| `fonts/` | Fraunces and Hanken Grotesk, Latin subsets, with their SIL Open Font Licence texts. |
| `images/` | Concept-page images and zoom tiles, archetype emblems, favicon, and social card. |
| `audio/` | Twelve six-second bed loops (MP3, 48 kbit/s, with a 0.3 s margin each side so decoder padding never falls inside the loop) and two switch sounds (WAV). |
| `sw.js` | The service worker, generated by `tools/build_sw.py`. Precaches the shell so repeat visits and offline visits work. |
| `llms.txt`, `llms-full.txt` | Plain-text summaries for answer engines, generated from the page by `tools/build_seo.py`. |
| `tools/build_sw.py` | Regenerates `sw.js` from the page's own links. Run it after any change to the site, because the cache name is a hash of the shell. |
| `tools/build_seo.py` | Regenerates the visible FAQ, the JSON-LD, the head tags, `llms.txt`, `llms-full.txt`, `sitemap.xml`, and `robots.txt`. `--check` writes nothing and reports whether they are stale. |
| `tools/check_seo.py` | Checks the structured data, FAQ parity, anchors, heading outline, and generated files. `--schema PATH` also checks property names against schema-dts' `schema.d.ts`. |
| `tools/make_previews.py` | Cuts the readable preview crops for the portfolio cards from the zoom tiles. |
| `tools/make_assets.py` | Regenerates the studio's textures, emblems, beds, and switch sounds. Nothing in them is sampled. |
| `tools/set_site_url.py` | Rewrites the public address everywhere it appears. Use it when moving to a custom domain. |
| `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll` | Hosting files for GitHub Pages. |

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000/. Serve over HTTP rather than opening the file, because the studio fetches its audio.

## Moving to a custom domain

1. Add a `CNAME` file containing the bare domain, and set the domain under Settings, Pages.
2. Run `python3 tools/set_site_url.py https://your.domain/` to update the canonical link, social tags, structured data, the link Telltale copies, `404.html`, `robots.txt`, `sitemap.xml`, `llms.txt`, and `llms-full.txt`.
3. Run `python3 tools/build_sw.py` so the service worker's cache name changes.

## Regenerating the studio's media

    pip install numpy
    python3 tools/make_assets.py

The beds are encoded to MP3 with `ffmpeg`, which must be on the path.

## After editing the page

    python3 tools/build_seo.py
    python3 tools/build_sw.py
    python3 tools/check_seo.py

The concept-page images under `images/concepts/` and `images/work/` are not generated by this script.
